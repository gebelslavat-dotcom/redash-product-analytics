# Delivery Service: Product Analytics Dashboard

Продуктовая аналитика сервиса доставки — динамика роста пользователей, курьеров и заказов за август–сентябрь 2022. Дашборд построен в Redash на основе SQL-запросов.

## Данные

Датасет и платформа — [Карпов.Курсы](https://karpov.courses/). Запросы написаны под PostgreSQL.

## Стек

SQL (PostgreSQL — CTE, оконные функции), Redash.

## Вопросы анализа

1. **Как растёт число новых и общих пользователей/курьеров?** Новые пользователи выросли примерно с 500 до 1800 за 2 недели.
2. **Какова динамика прироста — есть ли замедление роста?** Курьеры растут медленнее пользователей — потенциальное узкое место.
3. **Сколько платящих пользователей относительно активных курьеров?** Платящие пользователи стабильно растут, превышают 4000.
4. **Как соотносятся первые заказы и заказы новых пользователей?** Общее число заказов достигло 6000+ в день.

## Структура репозитория

| Путь | Описание |
|---|---|
| `queries/daily_orders_analysis.sql` | Динамика заказов, первых заказов и заказов новых пользователей |
| `queries/running_arpu_arppu_aov.sql` | Скользящие ARPU, ARPPU и AOV по дням |
| `queries/retention.sql` | Когортный retention-анализ |
| `queries/revenue_share_new_old_users.sql` | Доля выручки новых и старых пользователей |
| `queries/cancel_rate.sql` | Динамика отмен заказов |

## Как запустить

Запросы написаны под PostgreSQL. Нужна БД с той же схемой (Карпов.Курсы, датасет сервиса доставки) — выполнить SQL-файлы из `queries/` напрямую в своей среде.
