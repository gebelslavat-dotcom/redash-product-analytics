# 📦 Delivery Service: Product Analytics Dashboard

## 📌 О проекте
Продуктовая аналитика сервиса доставки — динамика роста 
пользователей, курьеров и заказов за август–сентябрь 2022.  
Дашборд построен в Redash на основе SQL-запросов.

## 🎯 Бизнес-вопросы
- Как растёт число новых и общих пользователей/курьеров?
- Какова динамика прироста — есть ли замедление роста?
- Сколько платящих пользователей относительно активных курьеров?
- Как соотносятся первые заказы и заказы новых пользователей?

## 📊 Дашборд
🔗 [Открыть дашборд в Redash](https://redash.public.karpov.courses/public/dashboards/hoT8YDBXyqXsvIGNWU2ZCwg1u8ycvXZBYSlUaNFK?org_slug=default)

## 🔍 Ключевые метрики
- 📈 Новые пользователи выросли с ~500 до ~1800 за 2 недели
- 🚴 Курьеры растут медленнее пользователей — потенциальный bottleneck
- 💳 Платящие пользователи стабильно растут до 4000+
- 📦 Общее число заказов достигло 6000+ в день

## 🛠️ Инструменты
| Инструмент | Применение |
|---|---|
| Redash | Визуализация и дашборд |
| SQL (PostgreSQL) | Запросы с CTE, оконными функциями |
| Карпов.Курсы | Платформа и датасет |

## 📁 Структура
- `queries/daily_orders_analysis.sql` — динамика заказов, первых заказов и заказов новых пользователей
- `queries/running_arpu_arppu_aov.sql` — скользящие ARPU, ARPPU и AOV по дням
- `queries/retention.sql` — когортный retention-анализ
- `queries/revenue_share_new_old_users.sql` — доля выручки новых и старых пользователей
- `queries/cancel_rate.sql` — динамика отмен заказов

## 🧠 Что демонстрирует кейс
- Продуктовая аналитика на SQL: рост пользователей и курьеров, ARPU/ARPPU/AOV, retention, отмены.
- Сложные запросы: CTE, оконные функции, когортный анализ.
- Построение дашборда в Redash.
